# 2주차 실습: 변수와 자료형, 함수

## 학습 내용

- 변수와 자료형 (`int`, `float`, `str`, `list`)
- 함수 정의(`def`), 매개변수와 반환값
- 타입힌트: `def f(x: float) -> float`
- `f-string`을 이용한 출력
- 테스트 함수를 따로 만들어 함수 동작 확인
- `if __name__ == "__main__":`으로 직접 실행할 때만 테스트 실행

## 파일 설명

| 파일 | 설명 |
|---|---|
| `happy.py` | 이름을 받아 생일 축하 메시지를 출력하는 함수. 직접 호출, `for` 반복 호출, 문자열이 아닌 값을 넣었을 때(타입힌트는 강제되지 않음)를 테스트 |
| `bmi.py` | 몸무게와 키로 BMI를 계산하는 함수와 BMI에 따라 저체중/정상/과체중/비만을 판정하는 함수 |

## BMI 판정 기준

| BMI | 판정 |
|---|---|
| 18.5 미만 | 저체중 |
| 18.5 이상 25 미만 | 정상 |
| 25 이상 30 미만 | 과체중 |
| 30 이상 | 비만 |

## 실행 방법

```bash
python lab/week2/happy.py
python lab/week2/bmi.py
```

실행 결과 (`bmi.py`)

```
BMI: 25.31
Category: 과체중
```

## 알게 된 점

- 타입힌트는 코드를 읽는 사람에게 의도를 알려줄 뿐, 다른 타입을 넣어도 실행 시 오류가 나지 않는다. (`happy.py`의 `test_say_happy_birthday3`)
- 계산 함수와 판정 함수를 나누면 각각 따로 테스트하고 다른 곳(3주차 `problem.py`, HW01)에서 다시 쓰기 쉽다.
