# 3주차 실습: 리스트, 튜플·세트·딕셔너리

## 학습 내용

- 리스트 연산: 합병(`+`), 반복(`*`), 비교(`==`, `<`, `>`)
- 튜플(변경 불가), 세트(중복 없음, 순서 없음), 딕셔너리(키-값 쌍)
- `bytes`(불변)와 `bytearray`(가변)
- `all()`(모두 참일 때 참), `any()`(하나라도 참이면 참)
- 타입힌트 복습
- 반복문 안에서 사용자 입력 받기, 잘못된 입력 처리(`try`/`except`)

## 파일 설명

| 파일 | 설명 |

| `miniproject.py` | **미니프로젝트**: 딕셔너리를 이용한 연락처 관리 프로그램 (추가/삭제/검색/출력/종료) |

## 미니프로젝트: 연락처 관리

딕셔너리의 키를 이름, 값을 전화번호로 저장합니다.

| 메뉴 | 동작 | 사용한 문법 |
|---|---|---|
| 1. 연락처 추가 | 이름과 전화번호 저장 | `contacts[name] = phone` |
| 2. 연락처 삭제 | 이름으로 삭제 | `del contacts[name]` |
| 3. 연락처 검색 | 이름으로 전화번호 찾기 | `name in contacts` |
| 4. 연락처 출력 | 전체 목록 출력 | `contacts.items()` |
| 5. 종료 | 프로그램 종료 | `break` |

메뉴 번호가 숫자가 아니거나 1~5가 아니면 안내 메시지를 출력하고 다시 입력받습니다.

### 실행 예시

```
===== 연락처 관리 =====
1. 연락처 추가
2. 연락처 삭제
3. 연락처 검색
4. 연락처 출력
5. 종료
메뉴 번호를 선택하세요: 1
이름을 입력하세요: 홍길동
전화번호를 입력하세요: 010-1234-5678
홍길동의 연락처가 추가되었습니다.
```
